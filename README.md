# db2 architekci — demo

Pierwsza implementacja koncepcji: prosta nawigacja, redakcyjna ekspozycja portfolio, fotografia jako główna treść.

## Uruchomienie

```bash
npm install
npm run dev
```

Obrazy są obecnie ładowane bezpośrednio z db2.pl. W wersji produkcyjnej warto pobrać i zoptymalizować assety lokalnie.
